One joke, zero punchline drift. The program writes a single deterministic one-liner about AI coding agents — "'It works on my machine,' said my AI coding agent, who is the machine." — to /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt when that variable is set). Same bytes on every run: no input, no randomness, no network.

## Run it

```sh
python3 main.py
```
